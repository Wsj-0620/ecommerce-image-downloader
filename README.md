# 电商图片下载助手（Chrome 扩展）

在淘宝/天猫、京东、拼多多的商品详情页一键提取商品图片，支持**单张下载**与**批量打包下载（ZIP）**。

## 目录结构

```
ecommerce-image-downloader/
├── manifest.json          # 插件清单（Manifest V3）
├── background.js          # 后台 Service Worker：执行下载与 ZIP 打包
├── content/
│   ├── content.js         # 内容脚本：从页面提取商品图片
│   └── content.css        # 内容脚本样式：就绪提示角标
├── popup/
│   ├── popup.html         # 弹出窗口界面
│   ├── popup.css          # 弹出窗口样式
│   └── popup.js           # 弹出窗口逻辑：渲染图片、触发下载
├── lib/
│   └── jszip.min.js       # JSZip 本地打包库（用于批量打包）
├── icons/
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png
└── README.md
```

## 功能说明

- **自动提取**：打开商品详情页后点击插件图标，自动抓取页面中的商品图片（含懒加载属性 `data-src` / `data-original` 等，以及 CSS 背景图），并过滤掉 logo、图标、头像等无关图片。
- **单张下载**：在缩略图上悬停，点击「下载」按钮即可下载该图片。
- **批量打包**：勾选多张图片后点击「打包下载所选 (ZIP)」，自动打包为一个 zip 文件下载。
- **全选 / 统计**：顶部支持全选，实时显示「共 N 张 · 已选 M」。

## 如何在 Chrome 开发者模式加载测试

1. 打开 Chrome，在地址栏输入 `chrome://extensions` 并回车。
2. 打开右上角的 **「开发者模式」** 开关。
3. 点击左上角 **「加载已解压的扩展程序」** 按钮。
4. 在弹出的文件选择框中，选择本项目的根目录 `ecommerce-image-downloader`（即包含 `manifest.json` 的那一层）。
5. 加载成功后，浏览器工具栏会出现插件图标（可点击拼图/固定按钮固定到工具栏）。
6. 打开任一淘宝/天猫、京东、拼多多的**商品详情页**，点击插件图标即可提取并下载图片。

> 若修改了代码，回到 `chrome://extensions` 页面点击该插件卡片上的「刷新」按钮即可重新加载。

## 权限说明

- `downloads`：调用浏览器下载能力保存图片/ZIP。
- `scripting` + `activeTab`：在插件后安装等场景下，动态向当前页注入内容脚本。
- `host_permissions: <all_urls>`：商品图片常托管在 CDN（如 alicdn.com、360buyimg.com 等），需要跨域抓取图片二进制用于打包；下载本身也需要访问这些地址。

## 已知限制

- 部分站点 CDN 存在防盗链（校验 Referer），极少数图片在打包时可能抓取失败，弹窗会给出提示，其余图片仍会正常打包。
- 商品图片数量非常大时，打包会占用一定内存与时间，请耐心等待。
- 提取结果取决于页面当前渲染的 DOM，若详情图需滚动/点击「展开」才加载，请先展开完整详情再点击插件图标。
